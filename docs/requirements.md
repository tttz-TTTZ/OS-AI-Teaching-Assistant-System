# V0.2 产品需求（用户本轮需求整理）

来源：用户 2026-10-15 的 V0.2 升级指令；用户已明确以本条消息为需求依据。目标是在 V0.1 上增量建立教师/学生课程平台，保持可读性、稳定性、Windows 本地运行和真实联调。

## 架构与兼容

一个前端、一个 FastAPI 后端、一套关系数据库；不做微服务或两套角色数据库。现有实际前端为 React + TypeScript + Vite，原始需求描述为 Vue；用户已确认保留 React，增量升级。

保留 FCFS、AI 适配、章节练习、资料功能及现有数据。迁移前检查并备份数据库和上传目录，禁止删除原数据库；不自动向学生公开无归属旧个人资料。内容种子必须可重复、标为演示数据，不能冒充正式课程。

## V0.2-A 账号权限

- users；教师/学生角色；安全密码哈希；登录/退出/当前用户；会话过期处理。
- 前端登录、角色跳转、路由守卫；后端真实权限检查，菜单隐藏不能替代授权。
- 本地账号初始化脚本，用户安全输入密码，无生产默认账号或硬编码密码。
- 2026-10-16 补充：网页区分学生/教师入口；学生可自行注册、成功后登录；教师仅登录，固定账号由管理员分配。注册只能创建学生，禁止通过请求参数自选教师角色或管理员权限。
- 学生不能写教师接口，不能读取其他学生文件；退出后会话作废。

## V0.2-B 课程内容

核心逻辑模型：users、courses、chapters、knowledge_points、documents、document_knowledge_points、questions。保留必要会话和原有问答记录。

教师：章节增删改、排序；知识点增改与章节归属；公共 PDF/TXT 上传、章节/知识点关联；内容发布和取消发布；简单表格表单和状态反馈；题目可先基础结构。

学生：仅浏览已发布课程章节和知识点、公共资料；个人上传、查看和删除；知识点打开关联资料；文件始终经后端授权，受控目录、随机文件名、类型和大小校验。PPTX 不在本轮必需范围。

## V0.2-C 页面

角色独立工作区，复用组件；学生首页紧凑课程概览、章节、最近发布资料、算法/练习入口；没有真实学习记录不显示虚构进度。知识点三栏：章节目录、正文、关联资料/实验。正文支持标题、段落、列表、表格、代码块样式。教师工作台以真实管理操作为主，不做虚构统计。统一间距、按钮、加载/空/成功/失败状态。

建议学生路径 /student/dashboard、materials、knowledge、experiments、ai-chat、practice；教师路径 /teacher/dashboard、chapters、knowledge、materials、questions；入口 /login。旧入口兼容跳转。

## 保留范围与非目标

FCFS 不依赖 AI；AI 未配置提示保留。此轮不要求复杂 RAG、AI 出题、数字人、主观题评分或复杂动画。不部署公网。

## 阶段与验收

依次检查设计→认证授权→双角色布局→课程章节/知识点→公共/个人资料→视觉联调→回归和文档；每阶段运行对应检查并汇报文件、功能、结果、剩余内容、启动和验收步骤。大规模框架替换、破坏性迁移或删除必须暂停说明。

必须验证：两角色登录；学生教师接口 403；已发布可见/草稿不可见；公共文件可读；个人文件跨学生不可读；退出会话失效；FCFS 回归；迁移不丢数据；刷新恢复登录。至少一个越权场景。环境限制项必须标明未验证。

交付源码、Windows 11/VS Code 指南、数据库设计/初始化、接口与测试说明。所有真实凭据不提交。

## 教材范围补充（用户2026-10-15确认）

校内优先，按《操作系统教程》第5版实际目录覆盖第1—7章：操作系统概论、处理器管理、同步/通信与死锁、存储管理、设备管理、文件管理、操作系统安全与保护。第8章作为拓展；考研范围标签延后并按实际大纲核实，不维护第二套重复内容。实施安排见 TEXTBOOK-CAMPUS-PLAN.md。章节号不得直接等同于现有数据库ID，目录对齐必须保留用户数据。


## 2026-10-16 数字教材增量授权

用户认可 KNOWLEDGE-LEARNING-SPEC.md 并要求开始升级试用。章节与页码尚未细致校对，必须允许教师自由修改、留空或标记待核对，不将平台教学编号与原教材小节号混同。先提供真实编辑/发布/学习/交互/练习闭环，之后逐步审核正式内容和增强交互。当前已实现与未完成范围以 DIGITAL-TEXTBOOK-DELIVERY.md 为准，不能声称完整教案已经审核上线。


## 教师编写动线补充（2026-10-16）

按用户试用反馈采用纵向、整页、按任务分步的工作区：先规划章/节和全部标题，再进入正文；一次只编辑一个内容模块。资料关联、预览发布、历史版本独立步骤；保留图片/图表/教学交互和练习入口，不在一个小区域堆满所有表单。章/节/编号/页码继续支持后续修订。操作与验收见 TEACHER-AUTHORING-UX.md。


## 学生学习动线补充（2026-10-16）

根据试用反馈，目录、教材、动画、资料、笔记和反馈不再同时拥挤呈现。先选知识点，再在全宽阅读区按模块阅读和观察，最后进入现有练习；资料与私人记录独立任务。保持阅读位置和笔记，失败不丢编辑，保留原权限与学习记录。当前实现和边界以 STUDENT-LEARNING-UX.md 为准。


## 算法实验平台升级（2026-10-16）

用户同意先梳理双端动线并升级。独立实验库与知识点教学关联；教师选择已有模板，维护目标/说明/观察任务/默认输入，试运行后发布；学生阅读任务、调整输入、运行回放、解释结果并保存本人观察。先交付 FCFS、非抢占 SJF、RR，不将运行或提交观察当成掌握。旧 FCFS API 保留；迁移前备份，运行与教学修订快照持久保存，其他学生不可读取。真实范围、阶段测试与后续项见 EXPERIMENT-PLATFORM.md。


## 大课件资料补充（2026-10-20）

用户要求上传约400页PPT课件。扩展PPT/PPTX原件上传、保存、授权下载和进度反馈；公共课件500 MiB、个人50 MiB；PPTX文字按页读取并可跳页，完整排版/图像/动画保留在原件，不伪装全保真网页预览。保留发布、章节/知识点关联、个人隐私、替换版本与成套备份；原PDF/TXT限制不变。交付与验证见 PRESENTATION-MATERIALS.md。


## DeepSeek辅助出题（2026-10-20用户新增授权）

用户要求AI从已有公共资料或教师专用上传资料生成题目并自动填写，教师审核后使用。覆盖此前“本轮不做AI出题”的非目标限制，采用独立准备工作区与现有题库复用。密钥仅后端；先预览实际摘录、再显式调用、持久候选、逐题审核、未发布入库、显式发布。资料与候选按教师权限读取，学生不得调用生成或读取未审核候选；来源、模型和处理状态可追溯。具体范围以 AI-QUESTION-GENERATION.md 为准，扫描OCR/全库RAG/自动发布不在本轮。

## PPT为中心的目录与教案备课（用户本轮新增要求）

教师以现有授课PPT为主要内容来源，不应被迫购买格式转换工具或逐条手写所有教案。支持旧PPT可解析文字直接提取，同时明确不兼容/图片文字边界；复用API根据摘录建议章内小节、知识点和结构化教案，供教师审核修改。章→任意数量小节→任意数量知识点，不固定全章小节数量；保留已有数据与修改章/节/编号/页码的自由。目录、整页正文、审核入库分步操作，默认只追加草稿，不自动发布或覆盖已存在课程。图片OCR/自动动画代码尚未实现，范围与证据以 AI-LESSON-PREPARATION.md 为准。
