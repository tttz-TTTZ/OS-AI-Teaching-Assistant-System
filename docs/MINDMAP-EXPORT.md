# 智能问答精简与思维导图导出

日期：2026-10-20。用户希望问答统一、减少顶部重复导航，并让 DeepSeek 按 XMind 结构生成可查看和下载的思维导图。后续将自行寻找 GitHub 上更成熟的导图方案，此项已记录。

## 本轮实现

- 删除旧基础问答 React 页面。`/student/basic-chat` 旧地址跳转智能问答，不提供第二套问答 UI。历史后端 `/api/chat`、健康检查字段与已有记录保留兼容，避免破坏旧 API 客户端；首页移除旧配置状态提示。
- 智能问答顶部仅标题与返回首页，移除顶部栏目；新话题移至对话区，不丢失重开话题功能。章节练习等页面可返回首页后从侧栏进入，个人自测仍可由工作台的测验成果打开。
- DeepSeek 提示词要求 XMind 的中心主题、分支和子主题结构，返回 `nodes: [{id, label, parent}]`。平台校验唯一根、非空标题、父节点存在、ID 不重复、无环和最多60节点；建议短标题、3–8个一级分支和2–4层，不为凑数量虚构资料。
- 用本地 SVG 绘制双向分支、连线、颜色和自动换行，支持适应宽度及75%/100%/150%显示，画布可滚动。历史节点格式不变，旧成果无需重新生成。
- PNG 下载：浏览器将当前完整导图转为图片，有白色背景；尽量2倍分辨率，边长上限8192、像素总量上限1600万，避免大图耗尽浏览器内存。SVG 可无损放大；导出不包含周围工具栏，不加载外部图片或脚本。
- XMind 下载：后端从本人已保存、校验过的模块创建 JSON 版 `.xmind` ZIP，包含 `content.json`、`metadata.json`、`manifest.json`，将节点转换为 `rootTopic` 和 `children.attached`，保留主题文字、层级和资料摘录笔记。由平台生成文件，不要求模型返回二进制，不把普通文本伪装为 `.xmind`。
- 导图与来源仍保存于现有个人任务 JSON，不新增数据库或依赖。图中模型文字通过 React 文本节点转义，不注入 HTML/SVG 代码。

接口：`GET /api/student/personal/jobs/{job}/modules/{index}/mindmap.xmind`。要求学生登录且为任务所有者，其他学生404、教师403；非导图模块422，不存在模块404；未登录401。文件响应禁用缓存。下载链接沿用独立标签会话选择方式，真正登录令牌仍在 HttpOnly Cookie。

## 验收方式与限制

1. 更新代码后重启前后端；进入智能问答，选已授权资料，点击思维导图。
2. 查看中心、分支与文字，调整比例，分别下载 PNG/SVG/XMind；刷新后成果仍可打开。
3. 用本机 XMind 打开下载文件，确认主题层级能继续编辑。云端没有 XMind 桌面客户端，文件结构与权限会自动验证，但客户端实际打开兼容性尚待实机验收，不能声称已验证所有版本。
4. 真实 DeepSeek 生成质量需配置后端密钥后验收；自动化使用模拟模型验证真实保存、图形渲染、下载和越权隔离。

当前结构是单根树；不支持跨节点关系线、图片/公式主题、拖拽编辑、云协同或双向导入。图形布局是平台生成的基础样式，并非完整复刻 XMind。旧记录不受新提示词的分支建议限制，仍按已保存树绘图。
