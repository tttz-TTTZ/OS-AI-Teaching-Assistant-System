# V0.3 · 第三版本

学生端删除知识点阅读与算法实验页面；教师端删除课程目录、知识点编写、章节内容导入发布和算法实验管理页面。删除首页、导航、练习结果及自主学习中的相关入口。旧地址返回对应角色首页；带 job 参数的旧学生知识点地址仍转到智能问答，保护个人生成记录链接。

保留公共与个人资料、智能问答、导图、闪卡、AI 自测、章节练习、教师题库与 AI 出题、账号管理、个人设置及学习反馈。

不删除数据库或已有记录。共享后端接口与数据结构保留，因为资料归属、练习筛选、来源引用、反馈及 AI 功能仍使用它们。此次删除的是指定产品模块的前端实现、路由和入口，不是清除所有相关后端数据和 API。

同时保留原文引用编号修复：在当前资料块内唯一匹配时兼容模型漏写的 -0；无效、跨块及歧义引用仍拒绝。

更新前按项目原有流程备份数据。前端运行 npm ci 和 npm run build；后端依赖沿用 backend/requirements.txt。更新代码并重启服务后才会影响已有部署。环境配置发布与 GitHub 推送是两个独立操作。

## 验证

- 前端 TypeScript 检查与 Vite 生产构建通过。
- 后端 auth、api、personal_chat、personal_learning、ai_questions、knowledge_pilot 共 82 项测试通过；模型测试使用替身，不代表真实 DeepSeek 服务可用性。
- 在隔离临时数据库中，以真实教师和学生账号运行 `scripts/v03-browser.cjs`：25 项检查通过，覆盖导航移除、保留页面加载、旧地址重定向，无浏览器运行错误或后端 5xx。
- 浏览器脚本使用 `TEST_ACCOUNTS_FILE` 指定验收账号 JSON，`BROWSER_EXECUTABLE` 可指定 Chromium；请只对隔离验收服务运行。

旧版本针对已删除页面的浏览器验收脚本仅作为历史记录保留，不再适用于 V0.3。其余功能未做穷尽式人工验收，真实 AI 调用和生产部署未在此次验证中执行。
