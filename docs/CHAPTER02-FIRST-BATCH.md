# 第二章第一批：预填内容、教师审核与学生学习

2026-10-22。在现有React/FastAPI工程上增量实现，没有替换框架、增加运行依赖或新增数据库迁移。

## 本次入口与结果

- 教师：`/teacher/chapter-content/chapter02`，从“知识点管理”或“课程目录”的“第二章预填与审核”进入。
- 三步动线：阅读一个预填单元 → 明确选择目标章、小节归属并检查 → 保存后审核、修改和发布。
- 内容：11份PPT/PPTX、169物理页的V1.1分析，24条稳定记录归入11核心+1可选进阶单元；普通摘要、4组关系图与F001/F004/F007/F009流程均复用既有结构化教材/图示组件。
- 实验：新增的是3份FCFS/非抢占SJF/RR的教学草稿和知识点关联，不是3套新算法引擎；计算与学生工作台沿用原实现。
- 学生：仍用 `/student/knowledge`，按章/小节进入已发布单元，一次阅读一个环节。图示支持节点选择、关系高亮、键盘、缩放与文字关系表；阅读位置可刷新恢复。
- “向AI问这个概念”进入独立智能问答，预填可编辑的问题并保留章上下文，不自动发送、不自动调用收费服务；没有模型配置时正式教材与算法仍能使用。

**保存草稿后学生看不到是正常行为。** 本章没有启动自动导入、自动替换或自动发布；第一章既有行为没有改变。

## 数据与兼容

1. 复用V9 `chapter_content_imports`、既有小节、知识点不可变修订、实验版本与发布事件；本次无新表和迁移。
2. 导入以课程+包ID+文件哈希登记；同包、同目标重复导入只返回原ID，不覆盖教师修改、移动、编号或发布版本。
3. 新建知识单元、小节、实验默认草稿；不会重命名目标章节，不清空旧知识点，不撤回第一章。
4. 现有小节编号和标题都匹配时可复用；有冲突则停止，教师可明确映射到同章已有小节。跨章映射拒绝，不猜数据库ID。
5. 全次导入在一个数据库事务内完成，任何内容或实验校验失败整体回滚。预览检查不写入数据库。
6. 同课程换目标或包版本改变时返回409，不静默重建；后续正文、标题、归属、自由文本页码仍由既有编辑器修改。稳定导入记录保留最初单元与数据库ID映射。
7. 原PPT没有随内容包导入文件存储。没有真实资料绑定时不伪造document_id/下载地址；教师可到公共资料管理关联已上传资料，学生仅看到有权限的实际附件。
8. 学生接口清空来源字段与图示编写备注；教师视图/存储保留来源、记录编号与V状态。学生的概念模型限制和适用条件仍保留。展示副本只在正文与原预填文本完全相同时替换，尊重教师后续改写。

## 教师浏览器验收

1. 登录教师，打开第二章入口。默认只看一个单元，可切换12个单元；来源、普通摘要和21项待核实独立折叠。
2. 进入第二步，明确选择本机真实的第二章。下拉选择是数据库实际章ID，不是“章号2=ID2”。没有章节可先创建。
3. 为2.1–2.5选择已有小节或使用默认新建/精确复用。点击“检查目标与目录”；冲突时明确映射，不会自动覆盖老师目录。
4. 确认目标后勾选“只保存待审核草稿”，保存12单元及3实验。第三步给出实际记录的修改、预览发布和小节编辑链接。刷新可重新读取此目标的导入记录。
5. 先检查课程、章、小节发布状态，再进入每个知识单元“预览发布”。可直接改现成内容，无需从空白手写。未发布或撤回的内容对学生不可读。
6. 对FCFS/SJF/RR进入现有实验预览，先试运行当前草稿再发布；没有发布的实验不会作为学生可用入口。
7. 到公共资料管理关联真实PPT。报告的物理页码是定位线索，不表示文件已上传、已绑定或原图细节均已确认。

学生验收：新开学生标签登录 → 知识点学习选实际章 → 打开已发布单元 → 分模块阅读/操作图示 → 刷新检查位置 → 已发布实验入口 → AI问答检查预填主题可编辑。正式练习为空时保持真实空状态，不将个人AI题计入教师成绩。
