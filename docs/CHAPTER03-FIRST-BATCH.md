## 已完成的范围

- 21条分析记录按主归属去重为12个预填单元；包含目标、原理、对照表、规则和条件、示例、易错点及回顾。8项普通内容融入基础速览；近似策略、反置表和段增长放到可选进阶。
- 复用现有 `ContentView`、`KnowledgeDiagram`，接入6幅关系图（45条命名关系）和9幅流程图。节点选择、键盘操作、关系导读、缩放由原组件提供。分支条件、等待和异常在图或正文中保留。这是静态教学图示，不是可执行的分配/置换/缺页状态机。
- 新教师入口 `/teacher/chapter-content/chapter03`：阅读一个单元 → 选择课程下真实章节与小节映射 → 保存草稿 → 进入既有编辑/预览发布界面。完整分析记录、独立文件物理页引用及28项待核实问题供教师核对。
- 标题、章号、页码、顺序和归属使用现有编辑器修改；报告中的稳定编号用于追溯，学生阅读不展示内部编写编号。来源字段保留在教师/存储，学生保留学习条件和真实支持状态。教师后续修改的图示说明不会被预置展示副本盖回。
- 学生继续使用“知识点学习”的分模块阅读、位置恢复、私人笔记与反馈；可进入正式练习和带主题的独立AI问答。正式练习为空、未关联实际资料、没有发布实验时展示真实空状态。没有生成正式题目或个人AI内容，不发起付费模型调用。

本轮不增加分区、分页、页面FIFO/LRU/OPT/CLOCK等计算引擎，不新增机制动画。现有FCFS、非抢占SJF、RR仍是CPU调度引擎；不把FCFS等同页面FIFO、RR等同CLOCK，也不把memory占位模板包装成存储管理引擎。报告30项参考计算不是本轮应用引擎测试。

## 使用步骤

1. 更新代码并重启前后端，用已有教师账号登录。进入“知识点内容”或“课程目录”中的“第三章预填与审核”。
2. 第一页每次预览一个单元。来源与原分析、普通摘要和28项未解决问题分别折叠展示；不需要教师逐条录入21条知识点。
3. 第二页选择本机真实课程下的“存储管理/内存管理”目标章；标题以实际目录为准。默认不选中任何目标，不把课件章号3当数据库ID。需要新章时先在课程目录创建。
4. 建议目录保留3.1、3.2、3.3.1—3.3.6、3.4。跨反置/多级的单元默认归到3.3.6，可通过映射或现有设置修改。3.3.5即使暂没有独立卡也保留，避免错误抹掉课件原目录。新小节默认未发布；已有小节保持原名称、顺序和发布状态。
5. 点击“检查目标与目录”。同编号不同标题或多条同编号不会自动合并，必须明确映射到目标章内已有小节。检查仅预览，不写数据库。
6. 核对后保存12个单元草稿。第三页提供目录设置、正文编辑和预览发布链接。先发布所用课程/章/小节，再由教师在每个单元的原预览页发布。未发布时学生不可见。本轮没有直接发布/启动自动导入入口。
7. 在公共资料管理关联实际上传的PPT；文件名与引用不是附件，不会伪造document_id或下载地址。正式练习仍由题库管理发布。
8. 学生登录后打开“知识点学习”，选择实际目标章：阅读一个单元 → 选择图示节点看关系或分支 → 记笔记 → 正式练习或具体向AI提问。个人AI自测与正式成绩分开。
