**后续教师操作改版：** 同屏编辑现已改成分步整页工作区，最新操作见 [TEACHER-AUTHORING-UX.md](TEACHER-AUTHORING-UX.md)。下文描述的旧入口位置不再适用，内容与权限能力保留。

日期：2026-10-16（北京时间）。依据：KNOWLEDGE-LEARNING-SPEC.md，及用户最新要求“章节、页码尚未校对，需要自由修改；先升级尝试”。

这是可以真实编辑、发布、学习、运行交互和作答的增量版本。不是完整教案内容已经审核上线，也不是需求报告全部增强项均已完成。保留现有React/FastAPI/SQLite与账号、课程资料、FCFS，不删除原数据库。

## 一、本轮可以做什么

### 教师

- 章标题、排序、教材章号、PDF起止页可编辑；页码可留空。历史“对齐七章”工具仍是显式操作，未校对无需执行，不在启动时自动套用；已有数字教材或小节时，旧工具拒绝直接批量合并，保护版本结构。
- 在知识点管理维护小节标题、编号、排序和发布状态；知识点可暂不分节，可调整章节/小节归属和排序。
- 教学编号、来源书名/PPT名称、印刷页、PDF页序和说明均可修改。知识点页码采用自由文本，可填“待核对”、罗马数字或区间，不与数据库ID绑定。
- 用内容块编辑问题导入、概念、精讲、案例、易错点、总结、拓展阅读、图片、数据图表和教学交互。可移动、复制、删除块。
- 旧知识点保留旧正文；“补齐教案内容模块”只添加缺少的空模块，不覆盖已有文字。新建默认给出空教案结构，不自动录入未经审定的教材正文。
- 保存草稿；已创建知识点停笔2秒自动保存（可关闭，失败会暂停并提示）；预览、复制新草稿、发布、撤回、归档、历史阅读、恢复历史为新草稿。
- 修改草稿不改变学生已发布内容。并发编辑版本不符返回409，当前表单保留。
- 上传真实PNG/JPEG/WebP，单张≤10MiB、≤2000万像素；图注/替代文字与来源由教师填写。图片通过后端授权，发布前学生不可读，撤回后无其他已发布引用时直链拒绝。
- 图表自行填写标签、数值、单位和来源；不预置未经核验的Linux代码分类数量。
- 统一题库管理单选、多选、判断、简答、匹配/分类，选择关联知识点。多选完全匹配判分；简答有参考答案/解析，不自动评分。
- 查看真实学习记录人数、自评掌握计数、作答次数和学生主动反馈；私人笔记不在教师反馈接口中返回。

### 学生

- 按章—节—知识点浏览，搜索本章编号/标题/摘要，查看目标、内容块、图片、图表、随文交互和来源。
- 本页锚点、字号选择、前后知识点、相关知识、资料阅读/下载、FCFS入口。
- 从知识点进入关联题组，提交后返回原阅读位置；未关联题目明确显示空状态，不混入全章题目冒充专项题组。
- 阅读标记、本人自评、收藏标记、阅读块位置和私人笔记可保存到数据库；刷新恢复。首页优先从账号记录继续学习。
- 交互完成、作答完成由真实运行/提交记录派生；不把打开页面当作掌握。
- 给教师主动发送反馈，与私人笔记分开。
- 保存的作答历史和错题可查询，保留当时题目和参考答案；重复提交同一请求不会生成两次成绩。

## 二、交互模板的实际范围

所有模板由服务器生成有序事件，前端提供播放、暂停、上/下一步、拖动回放、重置、倍速、事件日志。图解类另有直接场景按钮。倍速不改变计算结果，参数改变后必须重新生成事件。

| 模板 | 已实现行为与可调参数 |
|---|---|
| 空分内存 | 容量、A/B/C分配；显示分配与剩余；超容量明确拒绝 |
| 单核时间共享 | 任务数、统一CPU工作量、时间片、到达间隔、切换开销 |
| 单核/双核并发 | 核数、任务数、到达间隔、工作量、时间片、I/O延迟、切换开销；运行/就绪/等待/完成状态 |
| 虚拟打印队列 | 多任务提交、队列、单物理设备处理、完成计数 |
| 共享变量竞争 | 初始计数、有锁/无锁、顺序/交错；读—计算—写回及丢失更新 |
| 异步事件 | 修改I/O延迟，展示提交→等待→其他任务→完成→恢复的合法事件链 |
| 系统分层 | 四层解释、打开文件/播放音乐请求场景 |
| 四个观察角度 | 使用者、开发者、程序执行、资源管理切换 |
| 五个目标 | 目标、案例、收益与代价说明 |
| 五类资源管理 | 运行、内存、打印、保存、下载事件与多个管理模块同时高亮 |
| 管理员/服务员 | 两种教学视角切换，说明是比喻 |
| 系统模块与历史口径 | 模块职责与历史口径解释；精确图表由教师另行录入 |

以上是教学简化模拟和可点击图解，不是真实OS或正式性能基准。双核状态机测试避免同一任务在同一时刻被两个核心重复执行，并验证CPU总工作量。观察完成只代表完成学习操作，不作为可信考试成绩。

## 三、数据库与兼容

迁移版本4新增：sections、knowledge_revisions、content_events、knowledge_assets/revision_assets、knowledge_progress、interaction_runs、question_knowledge、study_attempts、learning_feedback；给知识点增加修订/编辑版本/归档字段，给题目增加题型/结构化答案/版本字段。

- 旧知识点、题目、用户、资料、关联ID保留；不重置演示数据，不修改用户本地原教材。
- 已有V3升级前自动成套备份到数据目录的backups/before-v4-*。更早版本沿用原迁移备份，不重复为同一次升级复制大教材。
- 原有知识点按需转为数字教材；第一次编辑旧已发布知识点时先保留旧发布快照，新保存只产生草稿。
- 新发布原子切换修订，同时更新旧接口兼容字段；已使用版本教材的知识点不能通过旧写接口绕过发布。
- 旧只读知识接口也检查小节可见性，不能绕过小节撤回。旧单选接口保留；新题型通过新版练习接口使用。
- 同课程内移动知识点时，其独用题目会同步调整章归属和版本；若与旧章其他点共用题目，先提示教师调整关联，避免静默错挂。
- 学习记录与作答绑定用户和教材版本。新内容版本提示复习，旧成绩与笔记不被清空。
- 图片放在现有受控uploads目录，成套备份/校验/恢复已包括图片引用。没有公开静态图片目录。

## 五、Windows更新步骤

先在你自己运行的前后端终端按Ctrl+C停止服务，不结束不认识的进程。建议先备份再更新。

### 1. 使用旧代码的工具先备份

在项目根目录运行（不要把备份放在Git仓库或uploads内）：

```powershell
cd D:\A-bishe\OS-AI-Teaching-Assistant-System
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
& .\.venv\Scripts\python.exe .\backend\storage_admin.py backup --output "D:\A-bishe\data-backup-$stamp"
```

工具使用后端配置的DATABASE_PATH并打包uploads，返回“备份及校验完成”后继续。备份包含账号和私人资料，放在自己受控目录。若仍缺filelock，先用当前仓库requirements.txt补齐旧依赖再备份。

### 2. 拉取并补齐依赖

```powershell
git pull --ff-only
& .\.venv\Scripts\python.exe -m pip install -r .\backend\requirements.txt
```

如果已经拉取了新代码，先补齐依赖再运行备份工具，在启动后端迁移前完成备份。

本轮新增Pillow用于实际校验教学图片；前端没有新增依赖。保留你的package-lock.json本地修改；如Git提示冲突，先检查，不执行reset/clean。无需重新创建虚拟环境、删除数据库或重新初始化账号。

### 3. 启动后端

```powershell
cd D:\A-bishe\OS-AI-Teaching-Assistant-System\backend
& ..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

启动自动兼容迁移；看到Application startup complete后继续。失败请保留错误输出和原目录，不用删库重建。

### 4. 第二个终端启动前端

```powershell
cd D:\A-bishe\OS-AI-Teaching-Assistant-System
npm --prefix frontend run dev -- --strictPort
```

用同一个主机名打开 http://127.0.0.1:5173/login ，旧页面刷新一次加载新逻辑。

## 六、浏览器验收路径

1. 教师进入“知识点管理”，新建一个明确标注“教学演示”的知识点，选择已发布章；小节可先不填。
2. 教学编号写“待核对”；在“来源、页码与相关知识”填写任意说明或留空。
3. 填写学习目标及六个基础内容块；添加一个“交互演示”块，选择空分内存，修改C分配。
4. 点击保存知识点。随后修改标题，停笔2秒看自动保存；此时学生仍看不到未发布内容。
5. 点击“学生视角预览”。核对后“发布当前草稿”。如果所属章/节未发布，会明确提示。
6. 学生新标签登录，找到该知识点；运行交互、单步、拖动回放至末步，记录观察完成。
7. 保存阅读标记和私人笔记，刷新确认保留；教师反馈接口不能读取私人笔记。
8. 教师在题库新增/编辑一题，选择该知识点并发布。学生从“练习本知识点”进入，提交并返回，显示已完成作答。
9. 教师更改正文并只保存草稿，学生刷新仍是旧发布版本；发布后提示内容更新，旧学习记录仍保留。
10. 撤回/归档后学生列表与直链不可读；历史版本可恢复为草稿再审阅发布。
11. 章节管理修改PDF页码、知识点修改来源页码，确认无需改代码；不要为了对齐目录先删资料。

## 七、本轮没有宣称完成的增强项

- 没有录入并核对教案全部12点的正式正文、题库、教材页码或PPT来源。
- 当前交互是模板化教学状态与回放；任意进程数据表、自由编排每个事件/交错顺序、拖拽式分层分类、专用虚拟地址映射模拟器和更精细的图形动画仍需下一轮。
- 匹配/分类题使用可键盘操作的选择框；无拖拽计分。简答可作答并查看参考，尚无教师人工评阅工作流或AI评分。
- 已创建草稿自动保存；新建知识点首次需手动保存。学生学习记录手动保存；未提交练习答案仅保留本标签临时草稿，已提交结果才进入数据库。
- 收藏为持久标记，尚无独立收藏列表；相关知识是普通关联，尚无先修关系图/强制学习门槛。
- 草稿预览的图文即时更新；运行互动预览需先保存。历史版可阅读和恢复，尚无逐字差异高亮。
- 固定少量教师共享课程管理；未新增多课程授课/选课授权、多校隔离。
- 未实现视频上传转码、任意HTML/JS/iframe动画、RAG、自动教案导入、云端部署或生产运维。

这些增强项不以静态占位按钮冒充完成。当前可用路径全部有真实前后端行为；后续以这版试用反馈继续打磨。
