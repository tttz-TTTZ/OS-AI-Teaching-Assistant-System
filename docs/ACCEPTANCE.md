## 如何重复自动验证

从项目根目录（前后端启动参考 README）：

```bash
.venv/bin/python -m pytest -q
npm --prefix frontend run build
.venv/bin/python scripts/smoke.py
# 已有系统 Chromium 的 Linux 环境
BROWSER_EXECUTABLE=/usr/bin/chromium npm --prefix frontend run test:browser
```

没有系统浏览器时，从 frontend 执行 `npx playwright install chromium` 再运行 `npm run test:browser`。浏览器测试要求后端真实 AI **未配置**，以验证 503 提示；已配置真实 AI 时，请使用单独的本地测试实例和测试数据库，不要清除个人密钥。浏览器测试和 smoke 会创建再删除测试资料；若测试中断，可在资料页删除名称带 browser-test 的临时资料。练习不保存学情，聊天成功时会保存问答记录。

## 逐项手工验收

1. 按 README 启动服务，首页应显示章节与实际数据库状态；示例课程不显示虚构学习次数。
2. 点击侧栏六个入口，刷新各路由仍能加载。停止后端再打开首页，应显示错误提示；恢复后刷新。
3. 知识点页切换“处理机调度”，查看 FCFS 内容，点击实验入口。
4. 算法页加载示例 1：P1(0,4)、P2(1,3)、P3(2,1)，平均等待 2.67、平均周转 5.33。示例 2：P1(2,2)、P2(7,1)，空闲为 [0,2] 与 [4,7]，平均等待 0、平均周转 1.5。示例 3：同时到达，按输入顺序，平均等待 2.67、平均周转 4.67。
5. 添加/删除进程，尝试重复 ID、空值、负数、零运行时间；应被前端或后端拒绝。修改参数后旧结果消失。重置应恢复示例 1。
6. 资料页上传 UTF-8 TXT，再上传正常 PDF。查看、下载，检查文件大小与分类；删除个人资料后文件链接不可访问。非法扩展名、无效 PDF 头、非 UTF-8 TXT、空文件、超过 10 MB 文件应失败。公共示例无删除按钮。
7. 问答页在无密钥时应显示“尚未配置 AI 服务”，发送后错误可见，清空可恢复空消息。配置密钥并重启后，可自行验证真实供应商回答（会产生费用）；不称其为可靠资料问答。
8. 练习页选择章节和答案，提交后应显示服务器判分、正确答案和解析；重新练习可重选。
9. 打开后端 `/docs`，检查并试用新增接口。

## 可用于答辩的核心逻辑

- **FCFS**：验证进程输入 → 稳定排序 arrival → 当前时钟不足到达时间时插入 idle → 计算开始/完成/等待/周转 → 返回数组与均值。纯 Python 函数不需要 AI 或数据库，可独立测试。
- **文件**：先限制整个上传请求大小，再验证扩展名/内容与文件大小 → 生成 UUID 存储名 → 在 SQLite 保存原始名和元数据。下载仅接受资料 ID，不接受任意文件路径。
- **数据流**：React 页面 → api.ts 统一 fetch → Vite `/api` 代理 → FastAPI 请求校验 → SQLite / FCFS / 模型服务 → JSON → 页面状态。
- **初始化**：先升级旧资料表字段，再建课程/知识点/题目表。用 schema_versions 标记一次性种子，避免重启覆盖人工修改。
- **练习**：初始 API 不返回答案，提交后后端查询正确选项并判分；只验证当前练习，不虚构长期学习历史。
- **AI**：后端从环境或 .env 读密钥，只发往配置的 HTTPS 地址；未配置、上游失败、超时分别给出明确状态，不把上游响应原文或密钥发给前端。

## 实现边界

已实现：六页面核心流程、资料文件管理、数据库示例课程与题目、FCFS、客观题判分、AI 适配与无配置提示。

部分实现：课程和练习是少量人工示例；聊天按单问调用，不携带多轮上下文；知识点关联资料依赖章节名称；PDF 只查看存储，TXT 提取前 50000 字；文件格式检查不是杀毒或完整 PDF 解析。

尚未实现：账号授权、SJF、全文资料检索/RAG、AI 出题、主观题评分、自动知识图谱、学习记录统计、生产部署。没有把这些内容伪装成已完成。
