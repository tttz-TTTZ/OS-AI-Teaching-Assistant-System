用户反馈其考研学习安排覆盖前5章。该信息暂作为未来个人学习标签，不据此推断通用考研大纲：本书第6章是文件管理，未来是否属于考研要求必须核对目标考试/年份/院校大纲。近期不做考研模式、第二套课程或双份知识点。

## 与现有系统的兼容处理

现有7个示例章节不等于教材的7章，不能直接以数据库ID重新编号：

- 旧“进程与线程”“处理机调度”均归教材第2章。
- 旧“进程同步与死锁”归第3章。
- 旧“内存管理”归第4章。
- 旧“I/O管理”归第5章，旧“文件管理”归第6章。
- 新增正式第7章“操作系统安全与保护”。

实现时将教材章号与数据库主键分开；保留知识点/资料/题目ID及owner。先核对哪些记录仍是原始种子、哪些已经教师修改，再迁移关联；不按名称猜测并覆盖用户内容。旧拆分章节迁移关联后可归档或兼容跳转，不盲目删除。新增安全章的数据库ID不一定是7，界面仍显示教材第7章。

教材页码映射应保留 printed_page 与 pdf_page_index 区别；后续分卷资料还需标记该文件首个印刷页，不因为拆分而让引用页码归零。

## 两级建设目标

### 下一周：全七章有结构，两章有完整深度

- 7章目录按教材对齐，每章先有2–3个核心概念卡片：全课程14–21个入门知识点，不声称已覆盖全部小节。
- 第2章深入到6–8个知识点，优先处理进程/线程、状态转换、调度指标、FCFS。
- 第3章深入到4–6个知识点：临界区、PV、同步互斥、通信、死锁条件等。
- 全课程先有每章2道人工题（14道）；第2/3章各补2–3道，合计约18–20道，实际数量按审核时间调整。
- 原教材拆分文件覆盖第1—7章；只有解析/来源/定位校验后的内容才计入“可检索资料”。
- FCFS完整单步播放器仍为必交动画；其他算法不同时开工。

### 随后3—4周：补全校内课程

| 阶段 | 建议重点 |
|---|---|
| 第1周 | 七章结构、整书本地拆分/入库、第2/3章样板、FCFS播放 |
| 第2周 | 第4章存储管理内容，页面置换FIFO/LRU择一；继续补第2/3章题目和解释 |
| 第3周 | 第5章设备与第6章文件内容；磁盘调度/目录结构示意择一，不强求都做动画 |
| 第4周 | 第7章安全与保护、第1章概念校对、校内复习路径、全课程回归与演示材料 |

安全章不能仅因为系统已有登录就宣称完成教学：需要独立知识点、资料和练习。现有角色/文件授权可作为第7章“认证与授权”的实践例子；不做危险攻击演示。

考研标签在上述校内内容稳定后，再新增学习范围关联或标签，不复制教材内容。具体标签须有大纲依据和年份说明。

## 105 MB电子书：无需会员的本地拆分方案

提供 `scripts/split_textbook.py`，使用免费的pypdf。本工具不上传原件到第三方网站、不改原文件、不解密文件；按目录章范围导出，若某章仍大于9MiB，会继续按页区间二分，直到每份≤9MiB。这样能适配现有10MB上传上限，保留余量。单页仍过大时明确失败，不通过偷偷降低画质来完成。

105MB不能证明文件是扫描版。先在阅读器尝试复制一段正文，判断是否有可用文字层。拆分只解决大小和组织，不等于OCR或AI解析。

### Windows操作

先把本分支代码更新到电脑。电子书原件及拆分输出都放Git仓库外，例如 `D:\毕设资料\教材`。根目录PowerShell运行：

```powershell
# 只为本地教材工具安装可选依赖，不改变后端依赖清单
.\.venv\Scripts\python.exe -m pip install pypdf==5.9.0

# 先在PDF阅读器找到正文印刷第1页，记下实际PDF页序N（从1开始）
# 用实际数字替换 N，以下命令只预览，不导出
.\.venv\Scripts\python.exe scripts\split_textbook.py "D:\毕设资料\教材\操作系统教程.pdf" --body-start-page N

# 核对无误后导出全部校内1—7章；输出目录须尚不存在
.\.venv\Scripts\python.exe scripts\split_textbook.py "D:\毕设资料\教材\操作系统教程.pdf" --body-start-page N --output "D:\毕设资料\教材\校内1-7章" --write
```

注意N只是占位符，不能原样输入。例如正文第1页实际是PDF第18页，就将N替换为18；18仅为举例，不代表你的文件。

只处理样板第2/3章时加 `--chapters 2,3`。拆分输出名包括教材章号、分卷序号、原教材印刷页范围。一次输出的多个part应归同一章节。先抽查每章首尾页，再教师端上传为草稿，按授权范围决定发布。

如果PDF中途夹插、缺页或页序与印刷页码不是固定偏移，该工具的默认映射不适用，应先纠正页码映射；不要为了得到文件盲目导入错页。

此工具已使用450页合成PDF验证页码偏移、二分到大小上限、页序不丢不重、原文件哈希不变、拒绝覆盖、单页过大时不留半成品、越界拒绝。安装pypdf后可运行 `python scripts/check_textbook_split.py` 重复检查；未接触用户105MB原书，因此尚未验证其实际页码、加密状态、扫描质量或单页大小。教材全文及拆分文件均不提交GitHub。
