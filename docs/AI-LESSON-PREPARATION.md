# 从授课PPT准备课程目录、数字教案和题目

> 已被最新产品定位取代：教师不再备课，学生自主选择生成学习内容。教师备课生成、修改与入库接口返回410；旧任务保留本人只读，前端原入口跳转目录。当前操作请看 [STUDENT-AUTONOMOUS-LEARNING.md](STUDENT-AUTONOMOUS-LEARNING.md)，下文仅为历史实现记录。

本轮按用户反馈增量实现：授课PPT为主要来源，教师先审核AI建议，而非手工逐条写全部内容。保留已有资料、章节、小节、知识点和修订记录，不自动重新编号或替换已录入的正式内容。

## 现在怎么操作

1. 教师工作台或「课程目录 / 知识点内容」→「从课件智能准备目录与教案」。
2. 选择已有公共资料，或上传仅本人可读的备课资料；也可以复制课件文字，直接粘贴保存成TXT，无需购买转换会员。
3. 选本节课的物理页序，先点「提取并预览实际文字」。核对缺页、图片或图表信息，不把未提取的内容当作AI已经看过。
4. 选择所属大章（需要新大章时可先创建）。输入教案要求或粘贴原教案的结构约定，设置本批知识点数量上限1–8，明确调用DeepSeek。
5. AI返回章内小节和知识点建议。小节数、每节知识点数由内容决定，没有固定数量。默认要求学习目标、问题导入、核心概念、原理精讲、典型案例、易错辨析、学习总结与练习建议。
6. 在目录审核页改小节名称/编号、调整顺序、移除不需要的候选。可以选择已有小节追加；AI建议标题与已有小节唯一同名时会预选已有小节。不会改写已有小节名称/编号/发布状态。
7. 点「整页审核教案」，一次核对一个知识点，修改正文、目标和教师提示，也可把知识点移动到其他候选小节。正文模块纵向展开，支持Markdown。确认引用来自本次实际课件页。
8. 点「保存候选修改」后刷新仍能继续；勾选审核确认后「批量存为草稿」。新建小节和知识点均不自动发布。进入原知识点编辑器，补充动画/资料/图片，预览并发布。
9. 出题仍在「AI辅助出题」，选相同课件范围和已入库的知识点，生成题目并逐题审核。学生正文中的练习入口继续使用现有练习板块。

流程分开处理目录、正文和发布。已有章节与教材不一致时，教师在目录中修改原章节或创建正确章节，再为AI候选选归属；不把数据库ID当教材章号。

## 资料解析能力与限制

| 资料 | 当前能力 | 不能据此声称已实现 |
|---|---|---|
| `.ppt` | 直接读取OLE中的当前PowerPoint版本索引、幻灯片文字，支持Unicode文字；在没有Current User索引时只接受唯一文档版本，不混入历史版本、母版和备注 | 不是完整MS-PPT渲染器，不能保证任意旧PPT兼容，不读取图片文字，不运行宏 |
| `.pptx` | 既有安全ZIP/XML解析，按真实幻灯片顺序读取文字 | 不还原版式、动画、图片语义、讲者备注 |
| 文字PDF | 使用现有pypdf按范围提取，解析上限50MiB | 扫描PDF无OCR能力 |
| TXT / 粘贴文字 | UTF-8文字进入现有私有资料库，可供本人与AI备课/出题使用 | 不会自动还原课件页码或教材印刷页码 |

旧PPT不再一律要求另存后才能出题。解析失败会明确报错；你仍可使用免费LibreOffice另存为PPTX，或从WPS/PowerPoint复制文字，粘贴到备课页。这里没有新增Office转换服务，也没有新增OCR供应商或暗中上传整份文件。

图片占主要内容、扫描课件或复杂图示需要补充OCR/视觉识别，之后再增加独立可审核的图片提取流程；DeepSeek本轮文本接口不能直接理解所有课件图像。没有原始教案完整文本时，默认六模块不代表已复刻原教案的每个细节，可在「教案要求」中补充约定。

每份资料最多20页、最多5份、合计24000字；达到限制会在摘录预览提示。约400页课件按授课主题分批处理，不一次发送整份。专用资料上传限制沿用个人资料：PPT/PPTX 50MiB、PDF/TXT 10MiB；公共大课件可从已上传列表选取。旧PPT文字流上限64MiB、最多2000页、有限记录数量和嵌套深度，损坏/异常结构明确拒绝。

AI只生成文字教案和动画/实验建议，不会生成任意可执行动画代码。真实交互仍由教师在知识点编辑器选择已实现的教学模板，或关联实验库中的FCFS/SJF/RR。建议不能显示为已经可运行的动画。原图片/图表上传和交互配置继续保留。

## 数据与权限

- V7只新增 `ai_lesson_jobs`，保存当前教师、配置、来源快照/指纹、模型、状态、整份结构化候选、编辑版本和导入ID。已有V6库迁移前成套备份到数据库旁 `backups/before-v7-*`，从更旧版本升级复用同次已有迁移备份。重复启动幂等。
- 生成前检查教师身份、原件所有权/公共资料权限、章节和来源指纹；学生403，其他教师的私有来源/任务404。引用要求逐字存在于来源，不接受空白伪造引用；这只核对出处，不证明AI解释正确。
- 同教师最多一个备课任务运行；请求标识及配置相同会返回已有任务，不重复付费调用。不同配置不能复用标识。90秒模型超时、不自动重试；五分钟以上运行任务在读取列表/详情时标记中断。
- 候选保存和入库均检查编辑版本；教师审核确认后，单事务创建小节和知识点修订。冲突会整批回滚，不留半批目录。重复入库返回409；同名已有小节需选用已有项，同节同名知识点拒绝追加，不覆盖旧内容。
- 候选编号和章/节归属可以后改。导入只建草稿；现有发布规则仍要求六类正文、学习目标及课程/章/小节均已发布。
- 只有点「保存候选修改」才会把编辑写回任务；刷新前有未保存提示。未调用模型前的资料选择不会跨刷新自动保存。没有后台队列、全课程自动重排或自动发布。
- 引用快照作为备课依据持久保存；删除原件不会自动删除已保存候选/已审核的教案正文。教师需在发布前确认私有资料中选出的内容适合学生阅读；原私有文件本体仍不公开。任务和资料本地保存不等于已部署云端或永久存储，沿用成套备份恢复。

## API和代码

`/api/teacher/ai-lessons` 下接口全部教师授权，写接口沿用CSRF：

| 方法和路径 | 含义 |
|---|---|
| POST /generate | sources、fingerprint、chapter_id、max_points、instructions、request_key；提取/模型调用/持久化候选 |
| GET /jobs | 本人最近30次任务 |
| GET /jobs/{id} | 本人任务、来源快照、候选和导入ID |
| PUT /jobs/{id} | plan、expected_version；保存候选 |
| POST /jobs/{id}/import | plan、expected_version、reviewed=true；单事务追加未发布内容 |

`plan={chapter_id,sections:[{section_id:null或已有ID,code,title,points:[{title,summary,objectives,blocks:[{kind,title,text}],source_ref,source_quote,teaching_note}]}]}`。每批生成上限8个知识点，编辑结构上限20个；不是课程总数限制。

后端 `legacy_ppt.py`、`ai_lessons.py`、`ai_lesson_migration.py`；前端 `AILessons.tsx`、`LessonSources.tsx`、`aiLessons.ts`。来源解析与出题复用，不维护第二套课程树或学生数据库。
