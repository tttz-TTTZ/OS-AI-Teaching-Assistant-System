# 学生知识点学习：目录与专注阅读改版

2026-10-16。依据学生端试用反馈：目录、整篇教材、动画、资料、练习、笔记与反馈同时挤在三栏中，学习主线不清晰。本轮拆分任务，复用现有已发布内容和本人学习记录接口，不改变课程内容或数据库。

## 新的学习动线

1. **选择内容**：进入“知识点学习”先看到目录页。选章节、搜索标题/编号/摘要，按小节查看知识点摘要，再点“开始学习”。目录页不混入正文、动画或笔记表单。
2. **开始学习**：进入知识点后先看摘要和学习目标，了解模块顺序。课程目录与正文不同时占据两列；需要换内容时用“返回课程目录”。从首页“继续学习”进入时，读取账号已保存的位置。
3. **阅读与观察**：一个全宽阅读区一次呈现一个模块。通过“上一环节 / 下一环节”按教师安排学习，也可用“本知识点学习导航”直接选择。图片、图表和交互动画保留在对应模块；字号可调整。这里显示的是环节位置，不是掌握百分比。
4. **练习巩固**：顶部随时有“练习本知识点”，最后一个模块提供“读完了，去练习”。前往现有练习页面，返回时保留知识点和原阅读模块。没有题目时仍由练习页提供真实空状态，不伪造完成记录。
5. **相关资料**：单独查看关联资料、来源与页码、关联知识点和 FCFS 实验入口。授权文件仍经后端读取，不暴露存储目录。
6. **笔记与反馈**：用整页空间写私人笔记、收藏、标记已阅读与自评。观察完成和练习作答状态读取真实记录，不把浏览当作掌握。主动给教师的反馈放在另一张独立卡片，默认折叠，私人笔记不会发送。

阅读页底部“学完之后”收纳写笔记、相邻知识点和 FCFS 入口，避免主阅读区域摆满同级按钮。教师端整篇预览仍保留，未强制教师使用学生的分模块呈现。

## 保存与异常处理

- 在阅读、资料和笔记任务间切换，私人笔记和当前阅读模块保持。切去笔记/资料时暂停当前动画，返回同一模块保留本页动画现场；切换到另一模块、刷新或离开知识点会重新初始化动画。后端已记录的观察完成状态保留。
- 切换模块更新待保存的阅读位置；点击“保存学习记录”后进入数据库。返回目录、切换知识点、进入练习/关联资料等本模块内导航，会先保存待同步记录；失败停留原页并保留文字。
- 未保存记录按账号和知识点暂存本标签的会话缓存，刷新后恢复；缓存不能代替数据库，关标签、清理浏览器或存储限制不保证恢复。浏览器不支持缓存时提示手动保存。
- 保存失败、并发版本冲突会给出提示，不覆盖服务器的新记录。提供“重新读取记录”，放弃未保存修改前确认；需要保留的本地笔记可先复制。
- 教材更新时提示旧版学习记录保留；若恢复到旧版未保存笔记，保留文字供核对后保存到新版本，不自动标记新版已掌握。
- 未发送的教师反馈在切换知识点或本模块内离开时提示确认；不自动发送。页面刷新请求浏览器离开提示。主站侧栏、浏览器关闭等行为受浏览器能力约束，不承诺所有导航都完成服务器同步。
- 旧的 `chapter`、`point`、`block` 查询链接继续支持；只传知识点 ID 时补齐章节。内容撤回、不存在、请求失败有错误信息和返回目录入口；搜索无结果与章节未发布内容为空分别提示。
- 学生仍只能读取已发布内容与本人的学习记录；本轮未新增后端接口、数据库迁移或运行依赖。

## 验收

先用教师发布一个含多个正文模块、一个动画、关联资料和题目的知识点。学生从目录进入，逐步阅读，直接跳转动画，生成事件并记录观察；切到笔记再返回，确认动画现场保持。写笔记保存、刷新确认保持，再做题返回检查原模块与作答记录。用另一个学生账号确认不能读取前一账号的笔记。

自动化使用临时数据库：`npm --prefix frontend run build` 和 `.venv/bin/python scripts/verify_v02.py`（云端 Linux）。浏览器检查覆盖目录搜索、目录/正文/笔记分离、正文区域宽度至少 700 像素、单模块呈现、Markdown 代码/表格、真实动画、笔记数据库保存和刷新恢复、模拟保存失败禁止离开、未保存记录恢复、资料打开、练习往返位置、独立知识点链接、640 像素窄屏无横向溢出、其他学生笔记隔离、无效知识点返回目录；同时回归教师编辑发布、注册、双标签登录、资料权限、FCFS 与练习。

本轮结果：前端类型检查与生产构建通过，HTTP 与完整浏览器回归通过，无 JavaScript 异常。后端代码未改动，未重复执行全量 pytest；现有权限、文件、练习接口已通过联调检查。

本轮为云端 Chromium 验证和截图检查，用户 Windows/Edge 人工验收及长期教学使用仍需后续反馈；未部署阿里云，不声称已完成服务器上线。
