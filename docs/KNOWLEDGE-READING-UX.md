# 知识学习阅读与交互优化

用户要求：来源不再展示给学生，学习环节按真实阅读和操作习惯组织。保留原内容、证据和修订，不重新覆盖数据库。

## 学生阅读

- 第一章以“想一想 → 抓住概念 → 理解原理 → 看图梳理/动手观察 → 看个例子 → 辨清误区 → 回顾要点”组织阅读；上方路线可跳转，下方可前后切换，原定位选择和阅读位置保存仍可用。
- 关系图/流程图放在原理后、例子前，不再落在总结后面。
- 不展示来源文件编号、页码、报告说明、核验待办和未开发动画占位。相关资料入口保留，供有实际关联附件时补充阅读。
- 教师端继续读取完整原文与来源；数据库、报告和历史修订不变。学生接口清空来源展示字段，第一章使用独立阅读副本清理编写说明。
- 阅读副本只替换与原规范文字完全匹配的段落；教师之后修改了正文时，按教师新文字显示，不用旧副本覆盖。模型适用条件、历史语境与关系方向不确定性保留。
- 正文按较舒适行宽与行距呈现；概念、误区、图解和实验入口有清晰层次。路线计数表示阅读位置，不显示虚构掌握度。

## 图示操作

- 节点支持鼠标和键盘选择，关联节点与连线高亮，其余弱化；正文说明区解释所选关系。
- 流程图可逐条查看关系/分支，不把它冒充算法执行或新的动画引擎。
- 支持放大、缩小、重置，长图在限定画布中滚动。
- 关系表默认收起，需要时展开；教师预览仍展开以便检查。
- 无箭头虚线仍表示方向尚未明确，不会为画面简洁而补猜箭头。
- 图示采用可访问分组与可聚焦节点，不执行任意模型代码。

## 动手与后续行动

- 教学交互运行后收起参数设置，集中看当前事件；需要调整时可以重新展开。
- 练习入口使用中性的“练习与自测”，保留知识点上下文，进入时重新读取实际题目；没有关联题时不虚构本节题目。
- 图解、例子、回顾环节可直接进入真实关联实验，并携带返回位置。
- 结束时优先进入配套实验；有正式题再进入练习，没有时可以记录理解。
- 移除强制猜测为FCFS的链接，RR知识点按真实实验关联进入RR。
