# 资料与个人 AI 学习：旧模块清理

本次删除教师练习题管理、AI 出题、学生正式章节练习，以及已经撤下的目录、知识点教材、算法实验的后端与持久化逻辑。学生个人 AI 测验保留，不再借用教师题库模型。

## 当前功能

保留账号登录、角色与个人资料隔离、公共资料发布、个人资料上传、文件预览下载、替换版本、回收站、智能问答、导图、闪卡、个人自测、个人笔记及历史记录。直接问答无需先有课程或章节，完整提炼按用户选择的资料和主题执行。

前端不再请求课程目录、知识点、题库接口。相关路由、页面、后端模块、初始化内容包写入器及专用旧验收脚本已删除；旧页面地址仅做重定向。AI 模型调用及个人自测校验已移至独立模块。

## 数据库升级

启动后端时迁移至 schema 10。支持本项目原 V8/V9 数据库及全新数据库；更老或未知结构会中止，避免猜测性丢数据。

现有数据库先使用项目的完整备份机制保存数据库与 uploads，并验证清单和文件校验和。备份目录位于实际数据库所在目录下的 `backups/before-v10-时间戳/`；`DATABASE_PATH` 自定义时以该路径为准。

删除活动库中的 courses、chapters、sections、knowledge_points、questions 及其教材修订、知识点进度、正式作答、学习反馈、实验与教师 AI 出题/备课、导入记录等关联表，并移除旧兼容视图。documents 不再保存课程/章节归属；personal_ai_jobs 不再保存章节外键，历史任务配置中的章节、小节关联同时移除。

用户、会话、账号审计、资料及文件版本、普通问答、个人 AI 历史、笔记、收藏、自测作答和资料索引保留原 ID。迁移核对保留表行数、SQLite 完整性及外键；失败整笔回滚。重复启动不重做清理，也不会重新生成旧目录、知识点或示例题。

备份中仍保留旧数据供恢复；上传文件目录不做批量删除，避免误删公共/个人资料及版本原件。数据库删除不等于安全擦除磁盘或销毁历史备份。

## Windows 更新

1. 停止所有正在使用该数据库的后端进程，另存一份现有 data 目录。
2. 在项目根目录拉取 `feat/development-foundation`；有本地修改时先妥善保存，不要强制覆盖。
3. 以前使用的后端启动命令重新启动服务；首次启动会自动备份并清理活动库，不必手工执行 DELETE/DROP。
4. 前端运行 `npm ci`，使用 `npm run dev`；若部署构建产物，执行 `npm run build` 后更新产物并重启相应服务。
5. 查看公共/个人资料、AI 历史和笔记，确认当前界面不再显示目录、知识点关联或练习题管理。

不要删掉整个数据库或 uploads。若迁移失败，先保留错误与备份；程序会回滚数据库。若需恢复迁移前版本，必须同时恢复旧代码和完整备份，不能只用旧代码打开已清理的库。

## 验证范围

自动化验证包括空库启动、V9 结构升级、备份与回滚、重复启动、权限隔离、文件版本/回收站/备份、文字/PPT解析、普通问答、个人自测与判分、导图闪卡完整提炼和模型适配错误。模型调用使用测试替身，不代表真实 DeepSeek 余额或服务可用性。

本次验证结果：后端全套 109 项测试通过；迁移专项复核通过；前端 TypeScript 与生产构建通过；隔离浏览器 28 项检查通过。
