## 本轮已落地的代码

### 数据与备份

- `main.py`：默认DATABASE_PATH相对backend固定解析，避免启动工作目录变化后误建空数据库；支持绝对路径；SQLite外键、30秒锁等待与WAL。
- `migrations.py`：保留原V0.2兼容迁移，新增版本3（账号管理员、资料sha256/来源/摘要、软删除、发布时间、教材章号/页码/归档、文件版本与账号操作审计表）。已有V0.2升级前备份，迁移可重复。
- `persistence.py`：跨进程filelock协调文件写入和备份；SQLite backup API + uploads + manifest SHA256；校验数据库完整性和引用文件。restore只允许不存在的新目录，不覆盖源目录，恢复后清空旧sessions。
- `storage_admin.py`：backup --output、verify --backup、restore --backup --into。本地CLI，不提供网页下载所有私人数据的接口。

### 登录与账号

- `auth.py`：`X-Session-Context`或文件链接session_context选择标签Cookie（os_session_<随机selector>）；selector不是凭据，真正令牌只在HttpOnly Cookie。无context的旧API客户端仍用原os_session，保持兼容。新增本人改密并撤销其他会话。
- 前端`api.ts`：sessionStorage仅保存标签selector，所有fetch带header；fileUrl给PDF/下载链接带selector。`/login?new_session=1`初始化新标签上下文；按用户最新要求，侧栏不再展示该入口，保留独立标签登录能力。
- `accounts.py`：普通教师管理学生；显式授权的is_admin教师才能创建/管理教师。创建、搜索、启停、重置密码，停用/重置立即撤销会话，不删用户资料。防止停用自己或停用最后管理员。
- `manage.py`：保留原交互创建，新增 --admin 与 --grant-existing。没有默认密码或自助提权；2026-10-16 新增学生自注册（/register + /api/auth/register），仅创建 student，教师仍由管理员分配。
- 前端新增teacher/Accounts和Profile页面，可创建/停用/重置学生账号、本人改密。

### 资料模块

- 教师公共PDF上限150MiB（覆盖105MB整书）；其他TXT/个人文件10MiB。UploadLimitMiddleware认证后磁盘暂存，避免大教材整包进内存；不能只改前端常量。
- `files.py`：暂存/文件校验/SHA256→同范围查重→受控目录原子改名→DB提交；失败清理未提交文件。公共上传草稿；替换保留旧文件版本并取消发布。
- 删除改为回收站，不永久unlink；restore恢复为草稿。私人文件、回收站和版本列表按所有权/角色授权。
- 列表SQL权限过滤/分页，仅返回元数据；正文用详情API。按标题、章节、状态搜索，关联知识点批量查询。
- 教师页上传章节和编辑章节分别保存，增加摘要/来源、筛选、回收站、替换、版本记录。
- 学生资料通过同一数据库/API读取公共发布资料和本人个人资料，个人回收站可恢复。

### 教材目录

`textbook.py`提供plan/apply：教师先预览，应用前自动成套备份，用fingerprint检测并发变化。合并旧“进程与线程/处理机调度”到教材第2章，更新已有知识点/题目/资料的chapter_id，保留内容ID与owner；旧章归档，不删除用户自定义章节。新增安全章。不是按数据库ID直接重编号。教师章节页有预览/确认按钮。

下一步让用户在服务器的PowerShell执行**只读**检查，逐步提供结果（先确认用户已进入远程服务器，不要误在自己笔记本运行）：

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object Caption,Version
Get-Service W3SVC -ErrorAction SilentlyContinue | Select-Object Name,Status
Get-NetTCPConnection -State Listen | Select-Object LocalAddress,LocalPort,OwningProcess
Get-PSDrive -PSProvider FileSystem | Select-Object Name,Used,Free,Root
```

结果用于确定可用目录/端口、有无IIS与现有网站；如不能判断现有项目用途，先与老师核对，不能为本项目破坏别的服务。密码/私钥不需要发给Codex。
