## 复核后的关键变化

- 资料范围明确为6份PPTX、118物理页；CLOCK第17页背景图、分页第6页图片解答、多级第12页图均不遗漏。
- 21条分析记录去重为12个建议单元；普通基础与可选进阶分开，不让学生面对21张重复卡。
- 明确S课件/T补充/V待核实；32条主要文字锚点可逐页定位，不把所有解释伪装成原文。
- 算法补齐预装历史、NF游标、稳定平局、计数/成本与完整分配布局条件；近似LRU无完整规则时不能提供唯一轨迹实验。
- 明确9/11/12与10/10/12是不同参数；额外4B表项假设下，11位索引下级表占8KiB，而非一4KiB页。
- 动画从需求句子展开为离散事件；暂停/回退保存完整状态，参考计算不等于动画已上线。
- 课件章号3不是数据库ID3；本章是否全部资料、教材/平台映射等仍未确认。

## 使用边界

- 当前已有正式计算引擎只有FCFS、非抢占SJF、RR；分区/页面算法均不能冒充已支持。现有memory模板仅是A/B/C示意。
- JSON是分析规格，不是直接数据库导入包；图坐标、字段名等还需适配现有模型。
- 原PPT/整页图片/完整转录没有上传仓库；文件关联需使用平台受控资料，不伪造附件或放宽个人文件权限。
- 暂未开发新算法、动画、迁移或自动发布。本章不能沿用前两章历史授权在启动时直接覆盖。
- PPT文字和静态画面检查不等于原生动画/宏/雨课堂交互已验证。V事项有建议解释也仍保留未确认。
