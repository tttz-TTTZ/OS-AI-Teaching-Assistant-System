## 产品范围

- 以本次6份教师PPTX、118物理页为依据，不使用教材PDF自动补成课件原文。
- 教师提供公共资料、调整目录、修改/审核/发布；由工程师预填，不要求教师手工输入21条知识记录。

- 学生可隐藏来源/编写备注；条件、限制和未支持状态不能隐藏。教师/存储保留来源、物理页、S/T/V及修改记录。

3. 静态关系图/流程图可复用图示组件。按S/T标明教学条件，V部分隔离，不能把模糊数字/代码补猜为确定原文。F004不得对未授权地址先调入；TLB命中不强制多访问主存页表，保持EAT模型一致。

## 第二批：新计算模型，分阶段测试

建议按独立里程碑执行：

1. 分页地址转换小闭环：输入→拆分→查表→地址或具体错误。
2. FF/BF/WF选择器；完整模式再加已分配/空闲/保留布局、释放合并和守恒。只给空闲表时不能凭空推断间隙归属。
3. NF：先确认/明确采用T的NF_v1；游标、切分、恰好用尽、回收后规则完整。
4. 页面FIFO/LRU/OPT：新引擎，新输入模型，先参考用例和边界，再播放器。默认空框；高级预装页要相应装入/访问历史等元数据。
5. CLOCK：先明确T的空槽/hand协议，扫描是独立事件；全R1的结束保证仅适用于无锁页、无并发插入的基础模型。
6. 缺页/脏页状态机：选择器与I/O分开，写回/读入/重试不混入引用A/F；失败不留下半更新或脏数据丢失。
7. 数组局部性、多级/段页式路径：从明确参数的小模型做起，原题和自拟示例保持独立。

每个阶段完成后报告：修改文件、功能、真实测试结果、未实现部分、启动命令、浏览器验收步骤。不要全部写完才测试。

- 课件章号、文件名、数据库ID不可混用；不写生产默认账号、不改用户模型密钥、不提交用户数据库和原PPT。
