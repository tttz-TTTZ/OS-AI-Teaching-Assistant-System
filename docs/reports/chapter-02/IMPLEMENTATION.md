# 第二章第一批开发：Codex 实施指令

本文件把V1.1分析报告转成开发入口。报告提交不等于用户已经授权把所有内容自动发布；第一章历史的“启动时直接覆盖发布”授权不能扩展为第二章的自动覆盖行为。用户要求后续开始实施时，按本文件增量开发，不只重复输出计划。

## 必须先读

1. 仓库适用的AGENTS.md（如有）与 `docs/requirements.md`。
2. [完整报告](REPORT-V1.1.md)，重点是质量复核、第4.1节去重单元、第7节算法边界、第9节V001–V021、第10节开发和验收。
3. `docs/KNOWLEDGE-READING-UX.md`、`docs/CHAPTER01-CONTENT-REVIEW.md`、`docs/CHAPTER01-DIRECT-APPLY.md`、`docs/EXPERIMENT-PLATFORM.md`及当前实际代码。旧历史交接存在不同阶段决定，冲突时以最新用户指令和本章范围为准。

## 开始前检查

- 检查Git状态和远程分支，保留未提交修改，不使用reset/clean消除用户文件。
- 检查知识点、数字教材内容块、章节导入、发布版本、图示、实验和资料权限已有模型/API，记录可复用能力。
- 先运行相关已有测试，检查依赖和启动方式，明确基线失败；不要把本章报告的分析参考计算当成新引擎测试。
- 检查现有数据库和上传目录。需要迁移时先备份、加法兼容、可重复执行；禁止清空/覆盖原库，不提交用户数据库、凭据或原PPT。
- 明确本轮修改文件和第一批范围后继续工作；只有遇到破坏性迁移、无法唯一定位课程或真正缺少必要信息时暂停相关操作，其余可独立工作继续。

## 第一批范围

1. 在现有正式知识点阅读和教师管理框架中增加第二章内容包及预填/预览/导入入口，复用现有数据和修订机制。JSON分析字段需映射到现有schema并校验，不能原样写库。
2. 按CH02稳定键幂等关联章节/知识点；章号、标题、顺序与物理页范围保持自由编辑。不要把章号2当数据库ID2；无法唯一定位时让管理入口明确选择目标课程/章。
3. 保留24条分析记录的追踪键，但学生按11个核心+1个可选单元阅读。普通摘要不强制独立卡；状态与队列共用事件/解释，指标只定义一次。第一章已有术语和RR引擎复用。
4. 先落地文字、对比表、核心流程及4组结构化概念关系图。复用 `frontend/src/learning/KnowledgeDiagram.tsx` 与现有内容块，保留关系标签、条件、键盘操作和文字等价说明；不要用大纲树替代关系图。
5. 优先U002/U004/U005/U007/U008/U009/U010/U011。工程师预填合理讲解/误解/例子，教师可以审核、修改、发布，不要求教师逐条从空表录入。第二章草稿与已发布状态明确；不在普通服务启动时静默覆盖已有内容。
6. 关联现有FCFS、非抢占SJF、RR，复用 `backend/app/scheduling.py` 和 `frontend/src/learning/ScheduleWorkbench.tsx`。案例与平局/时间片边界必须匹配项目现有规则。不开发重复RR或用SJF冒充SRTF。
7. 正式教师练习与个人AI测验保持隔离。没有正式题就展示真实空状态；不以个人生成题替代正式成绩。知识卡可带概念上下文进入独立智能问答，保留自由提问。
8. 学生不必看到来源/编写核验栏；后端和教师视图保留文件引用、页码、S/T/V/P、纠错和版本。草稿不可对学生读取，写入接口需真实教师权限，个人文件访问权不扩大。

## 不在第一批硬做的内容

- 新增SRTF、HRRF、优先数、完整反馈队列或彩票引擎；这些先保留概念/静态案例和真实未支持状态，不造可运行按钮。
- AN001–AN008复杂动画全部上线。现有关系边播放不是OS事件状态机。新机制演示后续按输入、前置、后置、不变量、快照回退独立开发。
- 任意AI脚本执行、原生PPT动画播放、Linux版本级源码/汇编复刻、真实内核交换器、大规模换框架/依赖。

## 待核实问题处理

- V001–V021逐项保留，不猜模糊原图，不静默改题干。80/30ms题和5/50ms例等不作唯一答案正式题。
- 第19页SRTF按报告输入复算为13ms；来源原错误仍留纠错记录。第32–33页是另一组输入，不要混淆。
- MLFQ完整迁移/抢占/量子/提升及彩票随机协议未定，不能从标题自动补成“课件确定规则”。
- 不调用教材PDF补写本章证据。原PPT不在GitHub，系统中缺实际document_id时保留来源描述并提供后续绑定，不伪造文件地址或称已链接。
- 教学补充例子明确标注；不是逐字原文。报告原文件哈希和40条引文定位可用于核对版本，但不是教师审核凭证。

## 开发顺序和验证

1. 基线检查与schema/兼容方案。
2. 内容包映射、幂等和草稿/预览/修订；测试重复导入不重复、目标章选择、旧数据保留、教师写权限与学生读隔离。
3. 学生单元动线和结构化图表；测试返回保留位置、键盘、加载/空/失败状态，不同来源/图之间不串页。
4. 实验/练习/AI跳转；运行报告第7节已有引擎案例和同到达、时间片边界、初始空闲等必要检查，保持现有算法回归。
5. 联调、修复与Windows启动/验收说明，标明真实验证范围和未验证项。

每一阶段先测试再进入下一阶段。验收依报告CH02-T001–T016，区分第一批适用项与暂未开发项；不得给新动画、新引擎或未经实测的Windows环境打勾。
