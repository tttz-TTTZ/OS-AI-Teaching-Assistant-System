## 使用边界

- JSON是分析交接规格，不是已经适配项目数据库的导入包，不可直接覆盖数据库。
- 报告中的S/T/V/P分别区分课件依据、教学补充、待核实、项目实际能力。V001–V021保持未解决；未澄清题目不得用于正式判分。
- 现有计算引擎只有FCFS、非抢占SJF、RR；SRTF/HRRF的参考数值正确不代表平台已有对应功能。
- 全页文字和静态巡检不代表所有图片细字或PPT原生动画均已验证。原始课件未提交到GitHub，实际资料关联应使用系统已有的授权文件。
- 学生端仍可隐藏来源栏，教师后台和存储保留引用、依据及修改记录。
- 此次未修改第一章、账号、用户上传、数据库或应用代码。

## 让 Codex 接着实现

可以把下述指令交给同一仓库的新Codex任务；不是要求教师手动录入24项内容：

> 请先阅读 `docs/reports/chapter-02/IMPLEMENTATION.md` 和完整V1.1报告，在现有项目中实施第一批开发。先检查Git、数据库与已有组件，再直接完成被授权的增量开发和逐阶段测试。复用FCFS/SJF/RR，不新增重复引擎；工程师预填内容，教师有审核与后续修改权；章节编号可编辑，不猜数据库ID。保留第一章与已有数据，未核实内容不发布为确定结论，不把新动画或算法标成已实现。完成后提供修改文件、测试结果、启动与浏览器验收步骤。
