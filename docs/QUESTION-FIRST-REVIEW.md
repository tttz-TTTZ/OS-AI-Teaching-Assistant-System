# 直接问答、知识成果与个人测验修复

2026-10-21。用户实际截图暴露三个问题：个人自测单选项排版被通用表单规则撑散；导图在未开启试点时继续使用前8块抽样；发送具体问题仍调用“生成学习模块”，模型返回普通回答时会被拒绝为类型不完整。

## 最终交互

- 中间输入框用于直接提问，“发送”或Ctrl/⌘+Enter走独立`/api/student/personal/ask`，不再调用生成explain模块。
- 不选资料也可以提问，显示“通用知识解释”；选资料时按当前问题检索，不再以之前文件名主题替代新问题。可取消“结合已选资料”，将当前问题作为通用问答。
- 资料无匹配或可读正文不足时，明确提示缺少资料依据，允许提供通用解释，不假装已读图片或来源。无权限资料仍拒绝，不能通过回退绕过权限。
- 支持连续追问、最近对话上下文、从上一份学习成果或已完成的个人测验继续询问。模型最多接收最近6轮、每条最多6000字符、合计24000字符的对话上下文；学习成果上下文最多12000字符。历史回答不作为新的课件证据。
- 问答和成果复用原个人任务存储和权限，回答可刷新读取、保存笔记，历史列表以“直接问答”区分。原每日个人任务配额仍适用，每次问答可能调用计费模型，不自动重试。
- 右侧只负责显式制作讲解、导图、闪卡、测验等材料。导图和闪卡默认先进行完整文字分批提炼，取消容易漏开的试点开关；不选具体小节时可整理本章的多份相关课件。选好资料和等级后单击工具直接生成；系统自动校验范围，可能包含多次模型调用。
- 保留120页/12批等边界；超范围明确提示减少勾选资料或拆分课件后上传，不悄悄退回目录抽样。单次最多5份来源，四份PPT流程有浏览器回归。
- 已保存的旧版导图继续可读，但出现重新生成提示。它们不会因拉取新代码自动变成新知识图，也不会被覆盖或删除。

## 测验排版

根因是`.authoring-form input:not([type=checkbox])`把radio也设成了100%宽度，label又是块元素。现个人自测使用独立选项布局，单选/多选框固定18px，文字紧邻控件，长内容在剩余空间换行；统一显示A/B/C等选项编号。旧题目无需重新生成即可应用新排版，答案索引和判分不变。

## 问答接口

`POST /api/student/personal/ask`请求：question、可选chapter_id、可选parent_id、sources、use_sources、request_key。

- 直接返回正文`body.answer`、`body.conversation`和有效引文`body.citations`，不要求modules。
- 无引文时标记通用解释；有依据的引文必须匹配本次实际检索片段。
- 先校验资料权限，再处理检索不足；模型调用后再次校验权限和资料版本。
- 父任务只能是本人；他人的父任务或记录404、教师调用学生个人接口403。
- 保留请求幂等、单用户任务互斥、失败记录、每日配额，不保存明文密钥。
- 继续使用后端DEEPSEEK配置，不再另建重复问答页面。真实模型回答的准确性仍需实际课件验收。

## 更新与验收

在项目根目录保存本地改动后执行`git pull --ff-only`，重启前后端，浏览器Ctrl+F5。本轮无新增依赖或数据库迁移。

1. 不勾选资料，直接输入“为什么虚拟机能运行不同操作系统？”发送，应出现正文回答，而不是学习类型错误。
2. 继续问“那它和真实计算机有什么区别？”，应使用上一轮上下文。刷新后仍能查看问答。
3. 勾选资料问具体术语，核对引用；没有匹配时必须明示通用解释。
4. 勾选四份相关PPT，点击思维导图即可直接生成，无二次确认。结果应由知识结论构造，不能只换一张目录图。超范围先减少勾选资料或拆分课件后上传。
5. 打开现有个人测验，检查单选框紧邻选项，长中文不会被挤到最右侧逐字换行。
6. 他人不能读取问答、成果或引用私人来源。
