# 智能问答：讲解、闪卡、测验调用修复

日期：2026-10-20。用户反馈三项功能均出现“DeepSeek返回格式异常或调用失败，未生成可用内容”。这条旧提示包含多个原因，不能据此认定是数据库、密钥或某一种模型错误。

## 查明的代码缺口与修复

1. 共用调用器将HTTP错误、网络连接失败、服务响应格式错误和模型正文JSON解析错误混为一条提示。现已分别报告404地址/模型、400/422参数、其他HTTP状态、网络/TLS、超时、非JSON服务响应、缺少choices/message、空最终正文、截断和正文JSON错误；不返回原始响应、密钥或请求头。
2. 服务地址总是追加 `/chat/completions`，用户若已填写完整路径会重复拼接。现兼容根地址、`/v1`和完整聊天路径，清理首尾空白；拒绝带凭据、查询参数或片段的地址。
3. 原先正文仅接受裸JSON字符串。现兼容完整JSON代码围栏、兼容服务的纯文本块数组；不提取任意散文中嵌入的JSON，不执行模型内容，不把reasoning_content作为最终正文。无效内容仍明确失败，不伪造成功。
4. 讲解、闪卡、测验原先共用一段全部模式的说明。现按任务生成提示：学习只输出modules，自测只输出questions；闪卡明确cards/front/back、至少3张，测验明确各题型答案编码。保留引用逐字核验、来源权限和结构校验。结构错误显示字段路径，不泄露模型原文。
5. 初始化用Promise.all绑定目录、AI状态、历史和算法列表，一个失败会阻断所有工具。现移除算法依赖，其余用独立结果处理；点击时重新检查AI配置，缺少来源或配置直接显示原因，不再无说明地禁用全部按钮。
6. 生成成功后必须再加载历史列表才显示结果，历史故障会遮住真实成功结果。现先显示并加入本地成果列表，数据库结果依旧真实保存。失败记录幂等返回HTTP200也不会当作成功；需明确点击可能计费的重新生成按钮，不自动重复调用。
7. 原先空主题使用章节标题做关键词检索，标题与课件用词不同就失败。新增明确的source_overview模式：未输入主题时概览已勾选资料，在授权页码范围中按资料轮流选最多8个片段，并展示范围限制；输入具体问题时继续按关键词检索，不把无关资料强行当依据。新字段保存在任务JSON，无表结构迁移。

## 动画范围调整

智能问答右侧的算法动画和AI概念演示生成入口已移除，个人自测后续学习设置也不再提供新动画选项。独立算法实验仍从首页进入，使用现有可计算、可测试的实现。历史学习记录与其旧演示保留兼容，不删除数据；后端旧模式不作为当前工作台新增功能。
