# 首页与学习模块入口调整

分支：`feat/development-foundation`。

- 学生首页标题为“操作系统AI助手”，提供课程资料、智能问答、习题归纳、学习模块四张圆角卡片。桌面横排，小屏自动换行；支持键盘焦点、悬停、进入动画及 `prefers-reduced-motion`。
- 习题归纳尚无对应聚合功能，仅提供待开发页；现有章节练习、个人自测和题库保留。
- 学生旧知识点阅读、实验列表/详情/运行结果地址均显示“学习模块 · 待开发”。带 `job` 的旧知识点地址仍兼容跳转智能问答，保留已有个人学习记录链接。
- 教师课程目录、小节、知识点编辑、课程内容导入和实验管理地址统一显示待开发页。公共资料、题库、账号与反馈保留。
- 旧页面源码及后端 API 保留；没有数据库迁移或删除操作。问答、课程资料、教师公共资料、账号和登录的实现未修改。新增 CSS 仅作用于首页卡片。

## 验证

在仓库根目录执行：

```bash
bash scripts/install.sh
npm --prefix frontend run build
.venv/bin/python -m pytest -q
.venv/bin/python scripts/verify_v02.py --foundation-only
```

专项验收创建独立临时数据库、随机账号和已发布小节，运行 HTTP 冒烟、首页/旧路由/资料上传发布下载/账号创建/登录退出/窄屏/减少动画检查，并复用 `personal-browser.cjs` 的完整问答验收。问答使用确定性模型夹具，不调用真实付费模型。测试退出时关闭自建服务并清理临时目录，不操作已有应用数据库。

原有浏览器全流程包含已撤下的课程编写与实验界面，仍保留作历史验收；此次界面请使用 `--foundation-only`。
