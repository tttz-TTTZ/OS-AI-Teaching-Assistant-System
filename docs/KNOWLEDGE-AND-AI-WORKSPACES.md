# 知识点学习与智能问答分工（2026-10-20）

本次按用户最新要求恢复正式课程知识点流程，将已有三栏 AI 学习工作台移到智能问答。不是重建数据库，也不清理历史内容。

| 使用者与入口 | 功能与操作顺序 |
|---|---|
| 教师：课程目录 | 建立、调整章/节，规划知识点标题 |
| 教师：知识点内容 | 选择知识点 → 全页编辑目标、正文、图片、教学模块、互动及关联资料 → 预览 → 发布 |
| 学生：知识点学习 | 选择章/节 → 选择已发布知识点 → 阅读、互动、笔记 → 关联资料、算法或练习 |
| 学生：智能问答 | 左侧公共/个人资料与页码范围，中间讲解、阅读、继续追问，右侧导图、闪卡、测验、代码、总结和算法入口 |
| 学生：章节练习 / 我的 AI 练习 | 教师正式题与个人生成自测分别保存；个人自测可带着疑问返回智能问答 |

教师人工维护内容的能力恢复；旧教师 AI 自动备课写接口仍停用，历史任务只读。AI 问答不自动变成教师审核过的教材。教师辅助出题保持原有审核流程。

## 路由兼容与数据

- `/student/knowledge`：正式课程目录和知识点阅读，继续支持 `chapter`、`point` 等参数。
- `/student/ai-chat`：三栏学习工作台，支持 `job` 恢复个人学习成果。
- 旧 `/student/knowledge?job=...`：保留全部查询参数，自动跳转智能问答；仍由后端校验本人权限。
- `/student/course-reading`：保留原阅读别名；新的相关知识点链接使用正式入口。
- `/student/basic-chat`：旧基础问答兼容入口，从工作台顶部进入，继续使用原 `LLM_*` 配置；主工作台仍使用 `DEEPSEEK_*` 配置。两者配置状态分别显示。
- 教师 `/teacher/knowledge` 和原编辑、发布 URL 恢复主导航入口。

不新增依赖或迁移；不修改课程、账号、文件、个人 AI 任务、笔记和成绩。未发布内容、私人资料和个人学习成果继续使用已有后端权限控制。

## 浏览器验收

1. 教师登录，侧栏进入知识点内容，选择标题，编辑内容后预览、发布。
2. 学生登录，进入知识点学习，检查章/节目录、已发布内容、相关资料与练习入口；草稿不可读。
3. 进入智能问答，检查三栏来源、学习对话与工具，恢复原个人成果。
4. 打开旧 `knowledge?job=任务ID` 链接，应跳到智能问答；刷新仍显示原成果。
5. 从个人自测输入疑问，点击带着疑问继续学习，应返回工作台并带入疑问与资料上下文；疑问不放入 URL。
6. 基础问答兼容入口仍可访问；模型未配置时应显示相应状态，不伪造回答。
